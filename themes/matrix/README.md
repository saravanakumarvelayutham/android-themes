# Matrix — Digital Rain

A coordinated static wallpaper theme with deep black, emerald code rain, and room for readable clocks and icons.

## Apply on your Pixel

1. Transfer `matrix-lock.png` and `matrix-home.png` to your phone.
2. Touch and hold an empty space on the home screen, then open **Wallpaper & style**.
3. Choose **Change wallpaper → Choose a photo** (some versions show **More wallpapers** first).
4. Apply `matrix-lock.png` to the lock screen and `matrix-home.png` to the home screen. Preview the crop before applying; preserve the dark central space.
5. Under **Colors**, choose a green palette matching the wallpapers.
6. Under **Icons → Style**, choose **Minimal** if available. On versions with **Themed icons**, enable that option for matching icons.

Google's setup reference: https://support.google.com/pixelphone/answer/7289143?hl=en

## Suggested styling

- Dark system appearance.
- Pale mint lock-screen clock; select a clean, simple clock style where available.
- One small clock/date widget near the top of the home screen.
- Keep the middle spacious, with frequently used apps near the bottom.
- Circular, minimal icons with green accents.

Palette: near-black `#020403`, dark emerald `#073A21`, code green `#39FF88`, pale mint `#C4FFDA`.

## Files and compatibility

These are wallpaper assets and a manual styling recipe, not an installable Android theme pack, launcher, or live wallpaper. No software installation is required. Menu labels and styling options vary with the installed Android version. The tall 9:20 artwork is designed for portrait phone cropping; it does not rely on an assumed Pixel 11 Pro display specification.

Artwork generated using the built-in imagegen tool. The exact generation prompts are saved in `prompts.txt`.
